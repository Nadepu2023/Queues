# Queues - Prime Calculator
## Overview

This project implements a queue-based prime number calculator. It demonstrates the use of data structures to efficiently compute and manage prime numbers.

## Features

- Efficient prime number calculation.
- Queue-based implementation for managing computations.
- Modular and easy-to-understand code structure.

## Prerequisites

- Python 3.x installed on your system.
- Basic understanding of queues and prime numbers.

## Installation

1. Clone the repository:
    ```bash
    git clone https://github.com/Nadepu2023/Queues.git
    ```
2. Navigate to the project directory:
    ```bash
    cd Queues
    ```

## Usage

1. Run the script:
    ```bash
    python prime_calculator.py
    ```
2. Follow the on-screen instructions to compute prime numbers.
